# Mad Scientist Jam 72 Clone — West Coast IPA

Clone recipe for Mad Scientist Jam 72, Hungarian Beer of the Year 2016. A classic West Coast IPA with tropical fruit, grapefruit, pepper, and pine hop character on a clean, dry malt base.

**Confirmed hops (from madscientist.hu):** Amarillo, Cascade, Chinook, Mosaic

## Targets

| Parameter | Value |
|---|---|
| Batch size | 20 L |
| OG | 1.065 |
| FG | ~1.010-1.013 |
| ABV | ~7.2% |
| IBU | ~65 |
| Color | ~8 EBC (gold) |
| Carbonation | 2.5 vol CO2 |

## Grain Bill (5.65 kg)

| Malt | Amount | % |
|---|---|---|
| Viking Pale Ale | 4.90 kg | 86.7% |
| Weyermann Munich I | 0.50 kg | 8.9% |
| Weyermann Carapils | 0.25 kg | 4.4% |

No crystal malts — clean, modern WC IPA approach. Munich I adds subtle bready depth without sweetness. Carapils provides body and head retention.

### Hop roles

- **Chinook** (13% AA) — bittering backbone, pine and pepper character
- **Amarillo** (9% AA) — primary aroma driver: tropical fruit, orange, grapefruit
- **Cascade** (7% AA) — classic citrus and floral, ties the profile together
- **Mosaic** (12.5% AA) — tropical complexity: mango, berry, stone fruit

## Mash

| Parameter | Value |
|---|---|
| Mash temp | 65°C for 60 min |
| Mash water | 18.35 L (pre-boil 24L - 5.65 kg grain) |
| Boil | 60 min |

Low mash temperature for a dry, fermentable wort — essential for the clean, crisp WC IPA finish.

## Water Chemistry

Target a sulfate-forward profile to accentuate hop bitterness and dryness:

| Ion | Target (ppm) |
|---|---|
| Sulfate (SO4) | 250 |
| Chloride (Cl) | 60 |
| Calcium (Ca) | 75-100 |
| SO4:Cl ratio | ~4:1 |

Build from RO or soft water with gypsum (~8-9g) and calcium chloride (~3-4g), split between mash and sparge.

## Yeast

**LalBrew BRY-97** — 2 packets (22g)

The cleanest dry yeast option for West Coast IPA: high flocculation, neutral profile, reliable 80% attenuation. Lets the hops dominate. Proven across 18 batches in this brewery.

## Fermentation Schedule

| Day | Action | Temperature |
|---|---|---|
| 0 | Pitch | 24-25°C |
| 0-3 | Active fermentation, free-rise | 25-26°C |
| 3-4 | Dry hop 1 (when within 5 pts of FG) | 22-25°C |
| 5-6 | Dry hop contact (3 days max) | 22-24°C |
| 7 | Cold crash, optional dry hop 2 | 0-4°C |
| 8-9 | Package | cold |
| 14+ | Ready to drink | serve at 8-10°C |

### Process notes

- **Dry hop post-fermentation, not during.** No biotransformation — this is a WC IPA, not a NEIPA. Clean hop oils, not yeast-derived fruit esters.
- **3 days max dry hop contact.** Longer risks grassy/astringent extraction.
- **Whirlpool at 80°C.** Cool wort to 80°C before adding whirlpool hops, steep 20 min. Extracts flavor and aroma without excessive isomerization.
- **Drink fresh.** Hop aroma fades fast — best within 4-6 weeks of packaging.
